# Movie Watchlist

## 1. Описание проекта

**Movie Watchlist** — кроссплатформенное мобильное приложение на Flutter для поиска фильмов и управления личным списком просмотра.

Приложение позволяет пользователям находить фильмы, просматривать информацию о них, сохранять фильмы в список просмотра, отмечать просмотренные фильмы, выставлять оценки и оставлять отзывы.

## 2. Цель проекта

Разработать удобное мобильное приложение для организации личной библиотеки фильмов с возможностью поиска, локального хранения данных и синхронизации пользовательской информации между устройствами.

## 3. Целевая аудитория

Приложение предназначено для пользователей, которые регулярно смотрят фильмы и хотят:
- сохранять фильмы, которые планируют посмотреть;
- отслеживать просмотренные фильмы;
- вести собственную историю просмотров;
- выставлять оценки и писать отзывы;
- получать информацию о фильмах в одном приложении.

## 4. Аналоги

- **IMDb** — каталог фильмов, информация об актёрах, рейтинги и пользовательские оценки.
- **Letterboxd** — личный дневник просмотров, оценки, рецензии и списки фильмов.
- **Trakt** — отслеживание просмотренного контента, история просмотров и персональные списки.

Movie Watchlist будет ориентирован прежде всего на простой персональный список фильмов и удобное отслеживание просмотров.

## 5. Основные экраны

1. **Главная** — популярные фильмы и рекомендации.
2. **Поиск** — поиск фильмов по названию и просмотр результатов.
3. **Информация о фильме** — постер, описание, жанры, дата выхода и рейтинг.
4. **Мой список** — фильмы, добавленные для просмотра, и просмотренные фильмы.
5. **Профиль** — авторизация, пользовательские оценки и отзывы.
6. **Настройки** — выбор темы оформления и управление настройками приложения.

## 6. Планируемые технологии

- Flutter и Dart с null safety.
- Material 3 для пользовательского интерфейса.
- Provider для базовых сценариев управления состоянием.
- Riverpod для основной бизнес-логики и внедрения зависимостей.
- Архитектура presentation / domain / data с использованием Repository.
- REST API для получения информации о фильмах.
- JSON для обмена данными.
- SharedPreferences для настроек и Hive для локального хранения фильмов.
- GoRouter для навигации.
- Firebase Authentication для регистрации и входа.
- Cloud Firestore для хранения и синхронизации пользовательских данных.
- Firebase Cloud Messaging для push-уведомлений.

## 7. Планируемая функциональность

В рамках первых восьми недель планируется реализовать пользовательский интерфейс, каталог и поиск фильмов, просмотр подробной информации, управление списком просмотра, оценки и отзывы, сохранение данных локально, базовый офлайн-режим, навигацию и авторизацию с синхронизацией данных через Firebase.

## 8. Этапы разработки

Разработка будет выполняться поэтапно в соответствии с учебным планом. На первых четырёх этапах будут реализованы интерфейс, управление состоянием и архитектура приложения. На пятом и шестом этапах — интеграция REST API и локальное хранение. На седьмом и восьмом этапах — полноценная навигация, Firebase Authentication, Cloud Firestore и Firebase Cloud Messaging.

**Текущий статус:** создан базовый Flutter-проект. Реализация функциональности Movie Watchlist находится на начальном этапе.
