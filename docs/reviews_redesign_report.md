# Редизайн списка отзывов — третий этап недели 6

## Что изменено

В `lib/presentation/screens/reviews_screen.dart` вместо одинаковых вложенных Material-карточек появился личный список: постер, название и год, компактные жанры, пять звёзд с половинным шагом и точная личная оценка по шкале 1–10. Текст рецензии показывается до трёх строк; длинная запись целиком остаётся сохранённой. Между строками — тонкие разделители, без карточки фильма внутри карточки отзыва.

В верхней части экрана добавлены поиск по названию фильма и тексту впечатления, а также три фильтра: все записи, с текстовым отзывом, только оценки. Число рядом с фильтром учитывает текущий поисковый запрос, независимо от выбранного фильтра. В общем списке оценки и текстовые рецензии разделены на секции. Пустая библиотека, пустая категория и пустой результат поиска имеют разные короткие подсказки.

Переход по записи передаёт исходный `Movie` и открывает его экран с параметром фокуса редактора. После прокрутки редактор виден сразу; после ответа каталога прокрутка корректируется повторно, поскольку метаданные могут менять высоту контента. Рейтинг и отзыв гидратируются из уже сохранённой записи. Переход не зависит от TMDB для нахождения фильма и не меняет запись.

## Ручная проверка

1. В своём профиле открыть «Отзывы», отфильтровать оценки и отзывы.
2. Найти запись по названию и фрагменту текста, очистить поиск.
3. Открыть запись, убедиться, что это правильный фильм и редактор виден сразу.
4. Изменить только оценку либо только отзыв и сохранить; проверить, что второе поле не стёрлось.
5. Перезапустить обычное `flutter run -d chrome` на исходном профиле и порту и проверить, что Hive вернул запись.
