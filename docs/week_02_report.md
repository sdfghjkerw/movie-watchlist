# Неделя 2 — статический интерфейс

## Требования курса

| Пункт | Реализация |
| --- | --- |
| 3–4 статических экрана | Главная, поиск, коллекция и страница фильма; общие демонстрационные данные без сети |
| StatelessWidget | HomeScreen, SearchScreen, WatchlistScreen, MovieDetailsScreen, MovieCard, MovieListTile |
| StatefulWidget | MainScreen: выбранная вкладка через setState; бизнес-логики коллекции нет |
| Row | Метаданные фильма и заголовок подборки |
| Column | Карточка фильма и группа действий на странице фильма |
| Stack | Постер-заглушка, рейтинг поверх него и подпись на странице фильма |
| ListView | Прокручиваемые экраны и горизонтальная подборка |
| Material 3 | Сохранены обе темы AppTheme; тёмная остаётся темой по умолчанию |
| Эскиз | week_02_sketch.svg: четыре экрана, иерархия, блоки и переходы |
| Структура | screens, models, widgets, theme сохранены; статические данные выделены в sample_data |

## Файлы

- lib/sample_data/movies.dart: существующие четыре фильма перенесены из главной без изменения сведений. Это учебные данные, не результаты API.
- lib/screens/home_screen.dart: сохранён дизайн; карточки открывают детали, кнопка списка открывает коллекцию; заголовок подборки переносится на узкой ширине.
- lib/screens/main_screen.dart: подключены поиск и коллекция; сохранены пять вкладок. Отзывы и профиль остаются заглушками.
- lib/screens/search_screen.dart: статическое поле и список фильмов, поле readOnly; реального поиска нет.
- lib/screens/watchlist_screen.dart: демонстрационные разделы «Хочу посмотреть», «Просмотрено», «Избранное»; это не пользовательское состояние.
- lib/screens/movie_details_screen.dart: статические сведения из модели, крупная заглушка постера и рейтинг через Stack. Недоступные действия отключены; отсутствующие метаданные не выдумываются.
- lib/widgets/movie_list_tile.dart: общая строка фильма для поиска и коллекции.
- test/week_02_ui_test.dart: переходы к деталям и назад, вкладки, статическое поле, отсутствие исключений компоновки на ширине 390 px в двух темах.
- docs/week_02_sketch.svg и этот отчёт: схема и подтверждения этапа.

## Соответствие схеме и ручная проверка

Схема отражает реализованную структуру: главная с горизонтальными карточками; поиск с полем и списком; коллекция с тремя разделами; детали с постером, метаданными, описанием и отключёнными действиями. Это схема, а не точный снимок интерфейса.

После hot restart в Chrome проверить четыре экрана, прокрутку, переходы по карточкам и кнопку назад; открыть SVG и сравнить расположение блоков. Ручная визуальная проверка обновлённого приложения в браузере в этом этапе не выполнялась. Светлая тема проверена widget-тестом; отдельный пользовательский переключатель не добавлялся.

Библиотеки не добавлялись. API, бизнес-состояние, базы данных и Firebase не реализовывались. Модель Movie, MovieCard, обе темы и учебные примеры сохранены. Недели 3–8 не начаты. Commit, push, смена ветки и настройки Git не выполнялись.
