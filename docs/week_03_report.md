## Ручная проверка сценариев

1. Выполнить полный restart основного приложения после добавления Provider.
2. Открыть фильм, прокрутить до кнопки, добавить его.
3. Вернуться и перейти в «Коллекцию»: фильм должен появиться в «Хочу посмотреть».
4. Удалить его из коллекции, открыть детали повторно: кнопка снова предлагает добавить.
5. Добавить несколько разных фильмов; переключение вкладок и маршрутов сохраняет список в текущей сессии.
6. Полностью перезапустить: список пуст — локальное хранение не входит в неделю 3.
7. Запустить каждую учебную точку входа и повторить 0 → 1 → 0.
