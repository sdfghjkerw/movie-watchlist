## Чек-лист курса

| Требование | Реализация и проверка |
| --- | --- |
| Источник данных | TMDB API v3: популярные фильмы, поиск по названию, детали по ID; нужен личный API-ключ |
| http или dio | http; запросы выполняются TmdbCatalogRepository |
| Таймауты | 12 секунд; тест зависшего запроса |
| Обработка ошибок | HTTP 401/403, 429, прочие неуспешные статусы, ClientException, таймаут, некорректный JSON; понятные сообщения без исходного ответа и ключа |
| Модели и JSON | MovieDto/GenreDto, json_serializable, сгенерированный movie_dto.g.dart; проверка round-trip |
| loading | Индикаторы каталога, поиска и деталей |
| success | Карточки, результаты поиска, детали фильма |
| error | Сообщение и повтор; исходный фильм остаётся доступен при ошибке загрузки деталей |
| empty | Отдельные сообщения пустого каталога и отсутствия результатов поиска |
| Debounce | 400 мс после последнего ввода; тест времени и отсутствия промежуточного запроса |
| Устаревшие ответы | Счётчик поколения запроса; поздний ответ старого поиска игнорируется |
| Pull-to-refresh | RefreshIndicator главной и поиска; ожидание запроса, обработка ошибки без зависшего индикатора |
| Сетевые данные | Реальные HTTP-запросы каталога, деталей и постера прошли; каталог и изображения видны в web-приложении |

Нет автоматического перехода на демонстрационные фильмы при отсутствии ключа: отображается ошибка настройки. StaticCatalogRepository сохранён для учебных примеров и независимых тестов.

## Запуск и ручная проверка

1. Получить API key v3 в https://www.themoviedb.org/settings/api (не путать с Read Access Token).
2. Остановить предыдущий запуск и выполнить:

```text
flutter run -d chrome --dart-define=TMDB_API_KEY=YOUR_V3_API_KEY
```

Заменить placeholder своим ключом локально. Не отправлять ключ в чат и не добавлять его в Git. Значения dart-define в web-сборке доступны клиенту: это не место для серверных секретов.

3. Проверить реальные названия и постеры, открыть фильм и дождаться деталей.
4. Ввести название, проверить результат после паузы, очистить и ввести заведомо отсутствующее название.
5. Потянуть главную и поиск вниз; при работе мышью можно имитировать touch через Chrome DevTools.
6. Отключить сеть в DevTools, повторить запрос: проверить сообщение и повтор после восстановления сети. Локального кэша ещё нет.
7. Добавить сетевой фильм в коллекцию, затем удалить; после полного restart список пуст.

Сейчас отображается первая страница каталога и поиска. Пагинация заданием недели 5 не требуется. Режиссёр, актёры и возрастной рейтинг пока не запрашиваются; сведения не выдумываются. Внешний источник может быть недоступен из конкретной сети; ошибки отображаются без подмены результата демоданными.
