# Неделя 6 — локальное хранение

## Состояние этапа

Функциональность реализована. Обычные автоматические проверки успешны. Полный перезапуск браузера и физическое отключение интернета ещё требуют ручной проверки; дополнительных браузерных тестов с успешным завершением получить не удалось. До недели 7 не переходим.

## Чек-лист исходного задания

| Обязательное требование | Реализация | Критерий и доказательство |
| --- | --- | --- |
| SharedPreferences: тема | SharedPreferencesAsync, тёмная/светлая/системная тема | Восстановление настроек новым экземпляром store и смена фактической темы в widget-тесте проверены; ручной перезапуск Chrome остаётся |
| SharedPreferences: язык | ru/en, локализация Flutter и текста интерфейса, язык TMDB | Сохраняется настройка; widget-тест проверяет пять вкладок и настройки на английском; HTTP-тест проверяет language=en-US |
| Hive или SQLite: кэш API | Hive, отдельный кэш каталога, деталей и поисков для каждого языка | Закрытие и повторное открытие Hive, сетевой сбой, пустой ответ и сохранность подробных данных проверены |
| Hive или SQLite: пользовательские данные | Список просмотра, избранное, история просмотренного | Записи восстанавливаются после закрытия и открытия реальных Hive-файлов; удаление из списка тоже сохраняется |
| Offline-first | Сначала кэш каталога, затем фоновое обновление | Тест с незавершённым сетевым Future проверяет немедленный кэш, затем обновление |
| Кэш при недоступной сети | Каталог, ранее запрошенные детали и поисковые запросы | Ошибки источника имитируются явно; данные приходят из Hive, не из демонстрационного источника |
| Основные экраны без интернета | Главная, коллекция, отзывы, настройки; сохранённые фильмы и поиски | Автоматически проверены репозитории и личные действия; ручной сценарий с отключением сети ещё нужен |
| Настройки между запусками | Настройки читаются до построения приложения | Проверено восстановление store и ошибки записи; реальный браузерный перезапуск вручную ещё не подтверждён |

Дополнительно по согласованному плану: личная оценка 1–10 и отзыв до 2000 символов, редактирование/очистка, рабочая вкладка отзывов, локальная статистика профиля. Это пользовательские данные недели 6. Регистрация и синхронизация не добавлены.

## Что изменилось и зачем

- `pubspec.yaml`, `pubspec.lock`: Hive, hive_flutter, SharedPreferences, Flutter localizations; shared_preferences_web в dev_dependencies для отдельной проверки браузерного backend.
- `lib/app/local_storage.dart`: открывает четыре отдельные Hive-базы и настройки; внедряет их через Riverpod overrides. Версия схемы отражена в именах баз `_v1`.
- `lib/app/providers.dart`: зависимости настроек, дневника, кэша и постеров; сетевой репозиторий обёрнут кэширующим. В тестах сохраняется явная подмена источников.
- `lib/main.dart`: загрузка хранилища перед запуском, применение темы и языка. При ошибке открытия показывает ошибку и повтор; данные не стираются и память не выдаётся за сохранение.
- `lib/domain/models/app_settings.dart`, `diary_entry.dart`, `lib/domain/repositories/diary_repository.dart`: независимые от Flutter/Hive настройки, личная запись и договор репозитория.
- `lib/domain/repositories/watchlist_repository.dart`: допускает асинхронное завершение записи, сохраняя совместимость с учебной реализацией в памяти.
- `lib/domain/repositories/catalog_repository.dart`: контракт возможностей кэша; presentation не импортирует конкретную реализацию Hive-репозитория.
- `lib/data/local/movie_codec.dart`: преобразование Movie в поддерживаемые Hive значения и обратно, без ключа TMDB.
- `lib/data/local/settings_store.dart`: SharedPreferencesAsync; тема и язык сохраняются одним JSON-значением, некорректные настройки заменяются значениями по умолчанию без удаления файлов.
- `lib/data/local/catalog_cache.dart`: сохранённые ответы и фильмы; краткий каталог не затирает подробные сведения ранее открытого фильма.
- `lib/data/local/poster_cache.dart`: сохранение байтов загруженных изображений, повторное использование без HTTP, заглушка при отсутствии картинки.
- `lib/data/repositories/hive_watchlist_repository.dart`, `diary_repositories.dart`: реальные операции Hive; вариант в памяти сохранён для тестов.
- `lib/data/repositories/offline_catalog_repository.dart`: кэш, обновление, fallback и признаки использования сохранённых данных.
- `lib/data/repositories/tmdb_catalog_repository.dart`: принимает язык запроса вместо жёсткого ru-RU.
- `lib/presentation/state/catalog_controller.dart`: немедленная выдача кэша и последующее обновление; защита от ответа старого экземпляра после перестроения.
- `lib/presentation/state/settings_controller.dart`, `diary_controller.dart`: сохранение до подтверждения изменения UI; последовательная запись настроек.
- `lib/presentation/state/watchlist_controller.dart`: ожидает завершения сохранения и восстанавливает актуальный снимок после ошибки.
- `lib/presentation/state/search_controller.dart`: повторяет текущий запрос при смене языка.

## Проверить вручную перед закрытием этапа

1. `flutter run -d chrome`: открыть фильм, добавить в список, избранное и просмотренное. Поставить личную оценку и отзыв. В коллекции и отзывах должны появиться эти записи.
2. Перезагрузить страницу: данные должны сохраниться. Затем выйти через `q` в терминале и снова выполнить ту же команду; проверить данные на том же адресе localhost:7357 и в том же профиле.
3. Удалить фильм из списка, убрать избранное/просмотренное, очистить оценку и отзыв через редактор. После перезапуска изменения должны сохраниться.
4. В профиле выбрать светлую тему и English, перезапустить. Тема и язык сохраняются; новый каталог/поиск получает данные на английском. Сохранённые личные записи не переводятся автоматически.
5. Онлайн открыть несколько фильмов, дождаться постеров и выполнить поиск. После отключения внешнего интернета, оставив локальный dev-сервер доступным, открыть главную/коллекцию/отзывы/те же фильмы и повторить тот же поиск. Сохранённые данные доступны; после неудачного обновления появляется пояснение кэша.
6. Новый, ранее не выполнявшийся запрос без сети должен показывать ошибку, а не выдуманные результаты. На первом запуске с пустым кэшем офлайн-каталог отсутствует — это ожидаемое ограничение.

Браузерное хранилище зависит от профиля и origin; очистка сайта или смена профиля/порта — отдельное хранилище. В debug-запуске Chrome Flutter использует временный профиль и сохраняет его в .dart_tool/chrome-device при завершении; аварийное завершение и удаление .dart_tool не являются проверенным способом сохранения. API-ключ остаётся в прежнем локальном JSON и в Git не добавляется.
